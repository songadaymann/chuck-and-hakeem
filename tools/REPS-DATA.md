# The phone book behind "CALL YOUR REPS"

`src/plugins/reps.js` reads static files in `public/data/reps/`. They are generated by `tools/build_reps.mjs`
(Node 22, no dependencies). Raw downloads are kept in `assets-src/reps/` (git-ignored).

    node tools/build_reps.mjs              # download the sources and rebuild
    node tools/build_reps.mjs --offline    # rebuild from the copies in assets-src/reps/
    node tools/build_reps.mjs --check      # compare 20 fixed ZIPs with house.gov's own lookup
    node tools/build_reps.mjs --check random:150
    node tools/build_reps.mjs --check 10001,90210

Last built: 2026-11-11 (the date is also in `members.json` as `built`, and shown at the bottom of the panel).

## What the build does

- **Members.** Names, parties and phones come from the two official lists. Every phone is compared with
  `legislators-current`; if the two disagree the number is NOT published and the panel offers the switchboard for that
  member. On 2026-11-11 all 539 numbers agreed. A number is only published if it has the shape 202-224/225/226-xxxx.
- **Vacant seats** (FL-20 and TX-23 on 2026-11-11) are kept as vacant: the panel says the seat is empty.
- **ZIPs.** One entry per ZCTA: `"10001":"NY12"`, or `"90210":"CA32:62,CA36:38,CA30:0"` when the ZIP area touches more
  than one district (the number is that district's share of the ZIP's land area, biggest first). Overlaps that are water
  only, and the Census "ZZ" pseudo-district (open water), are dropped. Delegates' districts ("98" in Census files) and
  at-large districts are both written "00".
- **ZIPs the Census does not draw.** For each three-digit start, the build looks at every ZIP it does have: when they all
  lie wholly in one state it writes `"008":"VI"` next to the ZIPs (803 of the 896 starts; the other 93 touch two states
  and get nothing). The panel uses it only for a ZIP that is not on file, says in so many words that it is going by the
  first three digits ("if that is where you live"), and then lists that state's senators. It names a House member only
  where the state or territory has a single seat; otherwise it sends the caller to house.gov's street-address lookup.
- **Output.** `members.json` (52 KB) and `zip0.json` ... `zip9.json` by first digit (38 to 69 KB each). A lookup fetches
  two files, at most 121 KB raw and about 28 KB gzipped.

## Caveats (read these before trusting it)

1. **A ZIP code is not a district.** ZIPs are mail routes; the Census "ZCTA" is an approximation of each one drawn from
   census blocks. Around 3 to 5 in 100 ZIPs contain some addresses in a district we do not list, and a few list a
   district where nobody lives. The panel says so and points to house.gov's street-address lookup. Senators are not
   affected (except caveat 3).
2. **Several thousand ZIPs are not in the file** (33,791 are; HUD's list has about 5,600 more): PO-box-only ZIPs,
   single-organisation ZIPs, and ZIPs created after 2020.
   For most of them the panel falls back on the first three digits (see above): senators for that state, the House
   member only where there is one seat (00801, a PO-box ZIP in the Virgin Islands, gets Delegate Plaskett), and it says
   it is going by the first three digits. A made-up ZIP with a real start (99999) gets the same treatment. Where the
   start is shared by two states or unknown (73301, the IRS in Austin) the panel offers the switchboard.
3. **137 ZIP areas cross a state line.** The panel then lists the senators for both states.
4. **When a ZIP is split, the percentage is land area, not people.** It is a hint, not a probability.
5. **These are the members in office now (119th Congress).** The Congress elected on 2026-11-03 is seated on
   2027-01-03. Some states used new district maps in that election; those maps apply from the 120th Congress. After
   2027-01-03: change `CONGRESS` and the Census file name in `build_reps.mjs` to the 120th relationship file (not
   published when this was written) and rebuild. The build stops if the Clerk's file is for a different Congress.
6. **Seats change.** Two senators (Husted, OH and Moody, FL) hold appointed seats that were on the ballot on
   2026-11-03; a special-election winner can be sworn in before January. The same goes for the two vacant House seats.
   Rebuild when that happens: it takes a few seconds.
7. **Who actually votes in the leadership elections** (members-elect of the next Congress) is not in this data. A
   member who is leaving has no vote in the caucus election; the suggested script does not claim otherwise, but it does
   ask.
8. **Names** are as the official lists print them (accents and nicknames included); senators' names are first name +
   last name from senate.gov.
9. The `--check` mode reads an HTML page on house.gov and will break when that page changes. house.gov's ZIP list is
   itself imperfect (it still lists some districts from older maps), so a difference is a prompt to look, not a verdict.

## Privacy

The ZIP is kept in the browser's localStorage (`chuck-hakeem-reps`) together with the Bioguide ids of members marked
"I CALLED" (each with the day of the last call) and a count of calls logged. The only network request a lookup causes is for `zip<first digit>.json` and `members.json` from this site.
The `called` event on the game bus carries chamber, party and state only; the core counts it (`src/net.js`) and sends
the server a bare number, so the national "calls made" total never learns who was called or from where.

## What the panel does besides look things up

- While it is open the player cannot be hurt (`player.safe` is held at one second) and no key reaches the game. Keys
  and buttons already held when it opens are let go (the panel sends the window the `blur` event the core listens for).
- Until the thumb that opened it has lifted, and for 450 ms after, it swallows clicks: on a phone the tap that opens it
  also lands on whatever the panel puts under the thumb, and that must never be a phone number.
- "I CALLED" is on the caller's word, once per member per device per day (offices count calls by the day). The server
  counts at most six an hour per player. Closing the panel after logging a call makes the player cheer, with confetti.
- On a phone the panel hangs from the top edge of the screen, so the ZIP field cannot end up under the keyboard.
